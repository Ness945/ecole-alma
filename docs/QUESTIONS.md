### Comprendre une histoire (`reading`)

#### read-find — trouver une information écrite dans un texte

Exemple montré en aide : Exemple : « Tom range ses crayons. » Qui range ses crayons ? On cherche dans le texte : c’est Tom.

1. « Le matin, Tom donne du pain aux canards. Les canards nagent sur la mare. » Que donne Tom aux canards ? — choix : du pain / du riz / des graines → **du pain**
2. « Mina a un chat gris. Il dort sur le canapé rouge. » De quelle couleur est le chat ? — choix : rouge / gris / blanc → **gris**
3. « Papa prépare un gâteau. Il casse deux œufs et ajoute du sucre. » Que casse papa ? — choix : deux œufs / un gâteau / du sucre → **deux œufs**

5. « Le facteur monte les escaliers. Il laisse une lettre devant la porte. » Que laisse le facteur ? — choix : une lettre / une clé / un colis → **une lettre**
6. « Lila range sa chambre. Elle met ses jouets dans une grande boîte. » Où Lila met-elle ses jouets ? — choix : sous le lit / dans l’armoire / dans une grande boîte → **dans une grande boîte**
7. « Dans la forêt, Emma voit un écureuil. Il grimpe vite dans un grand chêne. » Où grimpe l’écureuil ? — choix : dans un grand chêne / dans un buisson / sur un toit → **dans un grand chêne**
